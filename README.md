A parameterized asynchronous FIFO for reliable data buffering between independent read and write clock domains. The design uses Gray-coded pointers, two-flip-flop synchronizers, and full/empty detection logic.

**Contents:** [Features](#key-features) · [Architecture](#architecture) · [RTL Modules](#rtl-modules) · [Verification](#verification) · [Run in Vivado](#run-in-vivado) · [Structure](#repository-structure) · [Design Note](#design-note)

## Key Features

- Independent write (`wclk`) and read (`rclk`) clock domains.
- Parameterized data width and FIFO depth: `DEPTH = 2^ADDRSIZE`.
- Gray-coded read/write pointers for clock-domain crossing (CDC).
- Two-stage synchronizers for pointer transfer between domains.
- Full and empty flag generation using extended (one extra bit) pointers.
- Self-checking testbench with a scoreboard for read-data and ordering checks.

## Verification

The testbench (`tb/fifo1_tb.v`) checks reset behavior, data ordering, full/empty flags, overflow/underflow handling, and pointer wraparound. Every accepted write is stored in a scoreboard, and every accepted read is compared with the oldest stored word.

| # | Test case | Check |
|---|---|---|
| 1 | Reset | `rempty = 1`, `wfull = 0` |
| 2 | Write and read back | 10 words returned in the same order |
| 3 | Concurrent random read/write | No data or ordering errors |
| 4 | Overflow | `wfull` set, extra writes ignored |
| 5 | Underflow | `rempty` set, extra reads ignored |

Test setup: `wclk` period 10 ns, `rclk` period 20 ns, `ASIZE = 3` (depth 8).

| Recorded simulation summary | Result |
|---|---|
| Accepted writes | 40 |
| Accepted reads | 40 |
| Errors | 0 |
| Status | PASS |

## Run in Vivado

1. Add the six Verilog files in `rtl/` as Design Sources.
2. Add `tb/fifo1_tb.v` as a Simulation Source and set `fifo1_tb` as the simulation top.
3. Select **Run Simulation → Run Behavioral Simulation**.
4. Type `run all` in the Tcl console and check the final PASS/FAIL summary.

## Design Note

Gray-coded pointers minimize multi-bit transition ambiguity during clock-domain crossing (CDC), while two-stage synchronizers mitigate metastability propagation between asynchronous clock domains. Functional simulation validates FIFO data integrity, pointer sequencing, and status-flag behavior; CDC robustness and timing requirements should additionally be assessed through appropriate static analysis and implementation constraints.
